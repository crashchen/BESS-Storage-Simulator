# 矮横屏信息卡精简与SOLAR ARRAY标签避让

日期：2026-10-03（Europe/Berlin）。基线为main `9cc3661`（PR #23合并后）。分支`claude/compact-card-solar-label`有两个代码提交：`90d86c7`精简矮横屏卡片，`568d312`在卡片出现时隐藏SOLAR ARRAY标签。范围和约束来自用户转述的Codex意见：两项放同一批、分两个提交，桌面与竖屏布局不动。Codex已复审，未发现代码阻塞（见“Codex复审”）；尚未合并。未修改`GridState`、reducer、tick、dispatch、结算或配置数值。

## 问题与基线

两项来自[钉选卡记录](../2026-09-25/pinned-card-pcs-label.md#观感与后续设计)中用户提供的CC真实GPU报告：

- **矮横屏卡片过长**：`COMPACT_LEGEND_QUERY`（横屏且高≤430px）下，停靠卡片可视高度约200px，内容却有1300–1600px，需要滚六到七屏。
- **Solar标签被截断**：停靠卡片右缘只露出SOLAR ARRAY标签的“…RRAY”尾部。

本机main构建的测量（表1的main列）：七个矮横屏视口中，可视高度176–272px，内容853–1629px，约3.1–9.3屏。

## 改动

### 卡片摘要（`90d86c7`）

- **触发条件**：`SimulationViewport`用`useMediaQuery(COMPACT_LEGEND_QUERY)`把`compact`传给卡片。条件是媒体查询，不按卡片宽度判断：932×430的卡片宽约327px，同样显示摘要。
- **摘要内容**：标题与eyebrow（eyebrow改为句式大小写的小字），主读数与状态，进度条及其说明，BESS的读数说明（暂停、停止及各种限制原因），`summaryRows`（BESS非运行状态下的“Sampled operation”，即暂停快照的采样动作），单行列出的能流，以及“Station-level totals”站级提示。主读数块在矮横屏去掉外框，状态跟在数值后面。
- **Details折叠**：Key readings、设备说明（含station-level aggregates措辞与≈N×单元换算）和关闭提示放在Details之后。按钮带`aria-expanded`/`aria-controls`。这些字段都没有删除，只是默认折叠。
- **折叠状态的生命周期**：视口用钉选设备作为卡片的React key。同一设备的实时更新、抽屉临时隐藏卡片，都不改变展开状态。切换设备（工具栏、设备标签或本体）以及关闭后重开，都恢复折叠。附带效果：切换设备后的卡片从顶部开始显示。main复用同一个卡片节点，会保留上一张卡的滚动位置。
- **悬停预览**：不渲染Details按钮，卡内没有可聚焦控件。预览显示摘要和“Click object to pin this card”。
- **桌面与竖屏**：渲染与main一致。`summaryRows`排在Key readings最前，与main中“Sampled operation”的位置相同。浏览器实测内容高度与main逐像素相同（表1下方）。

### SOLAR ARRAY标签（`568d312`）

- `SceneLabel`新增`className`，Solar标签带`scene-label-solar`钩子，视口根节点带`scene-viewport`。
- `index.css`在同一短横屏媒体查询内加入`.scene-viewport:has(.scene-asset-card) .scene-label-solar { visibility: hidden; }`。钉选卡和悬停预览都会触发。卡片卸载后标签立即恢复：Close、Escape与抽屉隐藏已实测；Full site和点空白处同样卸载卡片。其他布局不受影响。
- 光伏板的零星边角仍可能露在卡片右侧。这是几何体本身，不在本批处理。

### 本机headless Chromium

**环境**：
- **驱动与浏览器**：Playwright 1.63.0驱动Chromium 153.0.8010.12 headless shell，运行于macOS（Apple M5）。Playwright借用本机另一项目的安装，不是本项目依赖。deviceScaleFactor为1，鼠标为CDP事件。PR #21的回归脚本额外使用CDP触摸事件，不是实体触摸屏。
- **构建**：两份构建都在`/BESS-Storage-Simulator/`子路径下，由本机Python静态服务器提供。
  - main：线上`abc6a32`构建的逐字节副本，与本机构建的`9cc3661`逐字节一致。
  - 分支：本批代码树的构建。
- **服务器卡顿**：服务器两次在加载阶段卡住某个请求，页面停在空白状态（568×320、844×390各一次）。脚本因此加了一次重载重试，并记录`loadAttempts`和失败请求；最终一轮12个视口都在首次加载完成。

**方法**：`docs/audits/2026-10-03/compact-card-check.mjs`逐视口执行：
1. 经工具栏依次钉选三台设备，记录卡片可视高度与内容高度。有Details时，用键盘走Close→Tab→Enter并记录展开后的高度。
2. 钉选BESS并展开后：
   - 等待3秒（模拟保持默认的停止状态，读数不变）；
   - 打开Metrics抽屉，再用Escape关闭；
   - 工具栏切到PCS再切回；
   - 点击GRID NODE标签；
   - 按Escape后重开，点Close后重开。

   每一步之后读取Details状态。
3. 钉选BESS后，用滚轮滚动卡片并比较相机位姿，再聚焦Close按PageDown和End。
4. 鼠标悬停三台设备本体，记录预览高度和卡内的可聚焦控件。
5. 无卡片、钉选、预览、关闭后各记录一次SOLAR ARRAY标签的visibility，以及标签矩形中未被卡片覆盖的面积。
